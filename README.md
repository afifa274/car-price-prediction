# 🚗 Car Price Prediction

A full end-to-end machine learning web app that predicts the resale price of used cars
using the **CarDekho** dataset.

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Python 3.10+ |
| ML / Backend | scikit-learn (Random Forest), pandas, numpy, joblib |
| Frontend | Streamlit |
| Charts | Plotly |

---

## Project Structure

```
car price prediction/
├── cardekho.csv       ← Raw dataset
├── requirements.txt   ← Python dependencies
├── train_model.py     ← Data cleaning + model training
├── app.py             ← Streamlit web app
├── model.pkl          ← Trained model (generated by train_model.py)
├── run.bat            ← One-click launcher (Windows)
└── README.md
```

## Quick Start

### Step 1 — Install Python
Download and install Python 3.10+ from https://www.python.org/downloads/
> ⚠️ During installation, tick **"Add Python to PATH"**

### Step 2 — Open a terminal in this folder
Right-click the `car price prediction` folder → **Open in Terminal**

### Step 3 — Install dependencies
```
pip install -r requirements.txt
```

### Step 4 — Train the model
```
python train_model.py
```
This will print the model's R² and MAE scores and save `model.pkl`.

### Step 5 — Launch the app
```
streamlit run app.py
```
Your browser will open automatically at **http://localhost:8501**

---

## OR — Double-click `run.bat` (Windows)
`run.bat` will install requirements, train the model, and launch the app in one go.

## Features

### 🔮 Predict Price tab
- Interactive form: select year, fuel type, transmission, owner, engine specs, etc.
- Instant price prediction with confidence range

### 📊 Data Explorer tab
- KPI metrics (record count, average/median prices)
- Price distribution histogram
- Price by fuel type (box plot)
- KM Driven vs Price scatter plot
- Transmission split (pie chart)
- Avg price by year trend line
- Raw data table preview

### 🧠 Model Insights tab
- R² Score & MAE on held-out test set
- Random Forest feature importance bar chart
- Average price by seller type & owner type

## Model Details

- **Algorithm:** Random Forest Regressor (200 trees, max depth 15)
- **Numerical features:** `car_age`, `km_driven`, `mileage`, `engine`, `max_power`, `seats`
- **Categorical features:** `fuel`, `seller_type`, `transmission`, `owner`
- **Preprocessing:** StandardScaler for numeric, OrdinalEncoder for categorical
- **Train/test split:** 80% / 20%
